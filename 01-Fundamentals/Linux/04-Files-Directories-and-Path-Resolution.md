# Файлы, каталоги и разрешение путей

## Цель

Понять, как Linux разрешает путь от текущего каталога до объекта и почему ошибки доступа или отсутствия файла не всегда означают отсутствие данных.

## Prerequisites

CLI и базовая модель Linux.

## In scope

Абсолютный путь начинается с `/`, относительный — с текущего каталога процесса. Для каждого компонента пути ядро проверяет существование каталога, права поиска (`x`) и имя следующего объекта. Право чтения каталога позволяет перечислять имена, но не гарантирует доступ к содержимому файла.

Специальные компоненты:

- `.` — текущий каталог;
- `..` — родительский каталог;
- `~` — разворачивание shell, а не особенность ядра;
- символическая ссылка — отдельный объект с текстом пути;
- bind mount — дополнительная точка доступа к существующему дереву.

Файл — это имя в каталоге, связанное с inode. Поэтому несколько имён могут указывать на один объект. Жизненный цикл файла зависит от ссылок и открытых file descriptors: удаление имени не обязательно немедленно освобождает место, если процесс продолжает держать файл открытым.

## Почему возникает «Permission denied»

Для открытия `/a/b/c` нужны права поиска на `/a` и `/a/b`, а затем права подходящей операции над `c`. Важны также владелец, группа, ACL, mount options и security policy. Проверка только прав самого файла неполна.

## Диагностика

```bash
pwd
namei -l /var/lib/example/data.db
stat /var/lib/example/data.db
readlink -f /path/to/link
```

`namei` помогает найти компонент, на котором ломается разрешение пути. `stat` показывает metadata, а `readlink -f` — итоговый путь после разрешения ссылок.

## Типичные ошибки

- использование относительного пути в systemd или cron без понимания working directory;
- ожидание, что `r` на каталоге даёт доступ к файлам;
- удаление файла, который всё ещё занимает место через открытый descriptor;
- путаница между symbolic link и hard link.

## Практика

Создайте вложенный каталог с разными правами на каждом уровне, проверьте доступ обычного пользователя и с помощью `namei` найдите блокирующий компонент.
