# Assessment и Definition of Done

## Цель

Проверить не объём прочитанного текста, а способность самостоятельно действовать: объяснить механизм, собрать факты, исправить проблему и доказать результат.

## Definition of Done для отдельной темы

Тема считается освоенной, если учащийся может:

1. объяснить её назначение и границы без чтения конспекта;
2. нарисовать поток данных или жизненный цикл состояния;
3. выполнить базовый сценарий в лабораторной среде;
4. назвать наиболее вероятные failure modes;
5. получить факты подходящими инструментами;
6. сформулировать проверяемую гипотезу;
7. исправить проблему с минимальным blast radius;
8. проверить, что symptom исчез и система не получила новый дефект;
9. сформулировать prevention action.

## Definition of Done для уровня

### Fundamentals

Можно объяснить процессы, память, файловую систему, сетевой запрос, Git и базовую shell-автоматизацию.

### Junior

Можно подготовить хост, настроить сервис, собрать контейнер, создать pipeline и воспроизводимо применить Terraform/Ansible.

### JuniorPlus

Можно развернуть базовый Kubernetes workload, PostgreSQL и monitoring stack, а затем диагностировать типовые ошибки.

### Middle

Можно эксплуатировать cluster, storage, replication, observability и messaging при обычных отказах и нагрузке.

### StrongMiddle

Можно защитить архитектурный выбор, объяснить trade-offs, найти bottleneck, спроектировать HA/DR и оценить failure domains.

### Production

Можно безопасно изменить систему, вести incident, выполнить rollback/recovery, провести postmortem и создать prevention plan.

## Финальная проверка

Итоговый сценарий должен включать:

```text
URL пользователя
  ↓
DNS → TCP → TLS → HTTP
  ↓
Load balancer → Ingress → Service → EndpointSlice → Pod
  ↓
Application → PostgreSQL
  ↓
Metrics → Logs → Traces → Alert → Incident
```

Учащийся должен объяснить каждый переход, показать источник фактов и обосновать следующий диагностический шаг.

## Не является критерием

- количество выученных команд;
- количество просмотренных страниц;
- знание десятков альтернативных продуктов;
- успешное выполнение лаборатории только по готовой инструкции.
